title: "이종 OS 아키텍처 설계 — Linux 컨테이너 + Windows 전용 서버 + Samba 연동"
date: 2024-08-12
context: "시공관리 종합 솔루션의 도면 변환 모듈이 Windows(Revit/애드인)에 종속되어 있어, Linux 기반 웹 서비스와 완전히 하나의 OS로 통합할 수 없는 제약이 있었습니다."
decision: "무리하게 하나의 OS로 통합하기보다 각 워크로드에 맞는 OS(Linux 컨테이너 + Windows 전용 서버)를 유지하고, Samba(SMB)로 파일 리소스를 공유하는 이종 OS 아키텍처를 채택했습니다."
alternatives:
  - option: "Windows 서버에 컨테이너 가상화 도입"
    cons:
      - "Windows 컨테이너 생태계 성숙도가 낮아 운영 복잡도가 오히려 늘어남"
  - option: "별도 외부 변환 전용 서비스 사용"
    cons:
      - "외부 의존성 증가와 도면 데이터 반출에 따른 보안 우려"
reasoning: "도면 변환 모듈은 Windows 환경에서만 동작해 완전한 Linux 통합이 불가능했습니다. 각 워크로드에 맞는 OS를 유지하면서 Samba로 파일 리소스를 공유하는 방식을 택해, 운영 복잡도를 낮추면서도 변환 파이프라인이 끊김 없이 동작하도록 설계했습니다."
